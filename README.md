<p align="center">A lightweight desktop music player for <a href="https://www.navidrome.org/">Navidrome</a> and other (Open)Subsonic servers.</p>

## Goals

- Small native binary — no Electron, no bundled browser
- Rust + [egui](https://github.com/emilk/egui) UI with a warm graphite / copper theme
- Playback via libmpv: gapless, ReplayGain, Opus and everything else ffmpeg can decode
- Optional server-side transcoding (e.g. Opus on a slow connection)
- OS media keys and now-playing integration (MPRIS on Linux, SMTC on Windows)
- Linux AppImage and Windows `.exe`, Flatpak later

## Status

Early development — nothing to run yet.

## Name

*Struna* is Czech for "string" — as in the string of an instrument.

<p align="center">Lehký desktopový přehrávač hudby pro <a href="https://www.navidrome.org/">Navidrome</a> a další (Open)Subsonic servery.</p>

## Cíle

- Malá nativní binárka — žádný Electron, žádný přibalený prohlížeč
- UI v Rustu a [egui](https://github.com/emilk/egui) s teplým tématem grafit / měď
- Přehrávání přes libmpv: gapless, ReplayGain, Opus a vše ostatní, co umí ffmpeg
- Volitelné překódování na serveru (např. Opus na pomalém připojení)
- Mediální klávesy a integrace se systémem (MPRIS na Linuxu, SMTC na Windows)
- AppImage pro Linux a `.exe` pro Windows, později Flatpak

## Stav

Raná fáze vývoje — zatím není co spustit.

## Název

*Struna* — jako struna hudebního nástroje.
